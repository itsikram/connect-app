# Settings Components

These screens match the web Settings page (`web/src/pages/Settings.js` and `web/src/components/setting/`).

## Sections

- **Profile** — name, username, nickname, display name, Bengali name, addresses, schools, workplaces
- **Privacy** — post / friend request / timeline visibility and location sharing
- **Notifications** — push and email alerts, unregister other devices
- **Account** — Bengali name, email, password, delete account
- **Preferences** — theme mode (Default, Dark, Light)
- **Messaging** — typing indicator, face mode, chat background upload
- **Sounds** — calling ringtone
- **Cache** — clear app cache
